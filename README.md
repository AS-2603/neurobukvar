# НейроБукварь

**Нейросети и ИИ простыми словами** — бесплатный учебный сайт для начинающих: 12 разделов, словарь терминов, частые вопросы, тесты и задания «Попробуйте сами».

**Сайт:** https://as-2603.github.io/neurobukvar/

## О проекте

Сайт объясняет, что такое нейросети и искусственный интеллект, как они обучаются и как ими безопасно пользоваться. Есть светлая и тёмная темы, сайт работает на телефоне, планшете и компьютере. Подробности — на странице [«О проекте»](https://as-2603.github.io/neurobukvar/o-proekte.html).

Сайт сделан с помощью ИИ: автор задавал темы, структуру и требования, схемы и страницы создавал ИИ.
